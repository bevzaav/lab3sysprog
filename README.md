# MiniC: транслятор підмножини C на Lex/Yacc (flex + bison)

Лексер `flex`, парсер `bison`, AST, інтерпретатор, трансляція в Python, візуалізація AST (D3.js, офлайн).

```bash
make                         # збірка, потрібні flex, bison, cc
make test                    # 19 перевірок
./minic examples/fact.c      # виконати (інтерпретатор)
./minic examples/fact.c --tokens | --ast | --json out.json | --py out.py
make view                    # зібрати web/data.js, потім відкрити web/index.html
make conflicts               # демонстрація shift/reduce та reduce/reduce
```

Прапорці `minic`:

| Прапорець | Що робить |
|---|---|
| (немає) | те саме, що `--run` |
| `--tokens` | друкує потік токенів лексера |
| `--ast` | друкує AST деревом з відступами |
| `--json ФАЙЛ` | записує AST у JSON для веб-візуалізатора |
| `--py ФАЙЛ` | транслює в Python і записує у ФАЙЛ (без виконання) |
| `--run` | виконує програму інтерпретатором; код повернення `main` іде в stderr |

Мова: int, глобальні/локальні змінні з областями видимості, функції та рекурсія,
if/else, while, do-while, for, break, continue, return, `print(...)`, повний набір C-операторів
(арифметика, порівняння, логічні, побітові, зсуви, тернарний, `=`, `+=` ..., `++`/`--`).
Не підтримується: масиви, вказівники, структури, інші типи.

Граматика не має конфліктів (`%expect 0`).
